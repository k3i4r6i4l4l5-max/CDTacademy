# Учебные сценарии CDTacademy

| Роль | Рабочие разделы | Действия |
| --- | --- | --- |
| Студент | Главная, каталог, занятия, конспекты, тесты, результаты, профиль | Читать опубликованное, выполнять задания, видеть свои попытки и комментарии, выбирать группу |
| Преподаватель | Рабочий стол, тесты, конспекты, проверка, группы | Создавать и публиковать материалы, импортировать документы, оценивать работы, распределять студентов по группам |
| Администратор | Рабочий стол, разделы преподавателя, аналитика, участники | Управлять ролями и аккаунтами, переходить от сводки к группе и попыткам учащегося |

Маршруты остаются доступны по прежним путям. Для прямого доступа к состоянию используются `/learn?lesson=…`, `/tests?view=results` и параметры раздела и фильтров на `/admin`. Права по-прежнему проверяет API.

## Модель и ограничения

- У конспектов и тестов появилось необязательное поле `placement` с дисциплиной, курсом и модулем. Старые записи без поля открываются как общие материалы. На API можно обновлять старые записи без передачи нового поля.
- Каталог строится из опубликованных материалов. Самостоятельная программа «Основы JavaScript» сохраняет прежний браузерный прогресс. Занятия этой программы распределены по модулям.
- Дисциплины, курсы и модули пока представлены метаданными. В модели ещё нет отдельных курсов с зачислением, расписания, дедлайнов, закрепления преподавателя за курсом и загрузки файлов в ответах.
- Состояния «На проверке», «Пройден» и «Не пройден» выводятся по фактическим попыткам. «Без отправки» указывает на отсутствие попытки в текущей выборке. Данные о просрочке и начале работы над серверным заданием отсутствуют.
- Динамика считается по датам отправки, в UTC. Групповая аналитика использует текущее распределение студентов. Самостоятельный прогресс хранится локально и в серверную аналитику не входит.
